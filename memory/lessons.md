## claude-code-platform
- ALWAYS send the user to the interactive `claude` → `/login` flow (local callback) rather than `claude auth login` when they are not at the terminal. Why: `auth login` uses a paste-the-code flow; a code pasted minutes later fails with the misleading `Login failed: socket hang up`. (seen: 1, last: 2026-10-31)
- ALWAYS spawn a nested `claude` with a sanitized env (drop `CLAUDECODE`, `CLAUDE_CODE_*`, `CLAUDE_AGENT_SDK_*`). Why: host-session vars made a 1 s headless start take 12 s. Fix: `packages/brain/src/engines/claude-cli.ts` `sanitizeEnv()`. (seen: 1, last: 2026-10-31)
- ALWAYS check login with `claude auth status` (JSON `loggedIn`), never with a paid probe call. Why: free, instant, and distinguishes "not logged in" from API errors. (seen: 1, last: 2026-10-31)
- NEVER assume the desktop app's login covers the CLI: `claude auth status` reported `loggedIn:false` while a desktop session was active. Why: separate credential stores; the user must run `claude` → `/login` once for headless runs. (seen: 1, last: 2026-10-31)

Why: the user saw "minutes with no usage" and nobody could tell the CLI's start from the vendor's API from a hung process. Fix: `notice` events, `RunTiming`, `SLOW-<run>` in `apps/server/src/brain-runner.ts` / `app.ts`. (seen: 1, last: 2026-11-02)

Why: `replyLanguage` sets `[[links]]` aside, so in `[[کار]] → memory/places/کار.md` the path's Latin letters won, the case ran as English and the brain answered in English, which the app never asks for. ## shell
- NEVER start an unquoted shell word with `=` in this zsh (`echo =====`). Why: zsh expands `=cmd` to the command's path and aborts the whole line with `==== not found`. Fix: quote it (`echo "====="`). (seen: 2, last: 2026-11-01)
- ALWAYS name a one-off tsx script outside the repo `.mts`. Why: outside a `"type": "module"` package tsx compiles `.ts` as CommonJS, and a top-level `await` failed with `ERR_REQUIRE_ASYNC_MODULE`. (seen: 1, last: 2026-11-01)
- NEVER edit source files with inline perl substitutions that carry non-ASCII text, backslash escapes or a delimiter character that also occurs in the text. Why: `-CSD` without `use utf8;` double-encoded Persian and em dashes, `\x27` became a literal quote that broke a TS string, and a `~` inside an `s~~~` replacement ended the expression. Fix: write the edit as a script file (`use utf8;`, unique delimiter), then `git diff` the result; for anything larger rewrite the file with a heredoc. (seen: 1, last: 2026-10-31)
- NEVER read a piped command's exit status through `${PIPESTATUS[0]}` in this zsh shell; redirect the output to a file and `echo exit=$?` instead. Why: zsh spells it `$pipestatus[1]`, so the bash form prints nothing and the typecheck result went unread. (seen: 1, last: 2026-10-31)
- ALWAYS feed JSON test payloads to hooks with `printf '%s'`, not `echo`. Why: zsh's `echo` interprets `\n` inside the payload and silently breaks the JSON, so the hook exits early and the test looks like a hook bug. (seen: 1, last: 2026-10-31)
