# Journal

- One node per day: `nodes/journal/YYYY-MM-DD.md`, `type: journal`, `date:`, `title: YYYY-MM-DD` (aliases may hold a Persian date), `summary` = the day in one line (update it as entries grow).
- Append entries under `## HH:mm` headings (reviews add a label: `## HH:mm — Daily review`); never rewrite earlier entries.
- Link what the day touched: tasks created/finished, people met, projects moved. Reflections and feelings go here, not into task nodes.
