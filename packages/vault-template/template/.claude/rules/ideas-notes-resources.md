# Ideas, notes, resources

- **Idea**: a possibility, "what if", something to explore. Body: the idea in the user's words, then why it matters and the next step when known, with lead-ins in their language (Persian **«چرا مهم است:»** / **«قدم بعد:»**, English **Why it matters:** / **Next step:**). Link to the project/area it could serve.
- **Note**: knowledge, facts, meeting notes, learnings. Body is the content; keep headings minimal. Set `project:`/`area:` when clear.
- **Resource**: an external thing — a link, video, reel, course, article, book, podcast, tool. `url:` when given; `kind`: `video` · `reel` (Instagram/TikTok/YouTube Shorts) · `course` · `article` · `book` · `podcast` · `tool` · `other`; `platform` (`instagram`, `youtube`, `aparat`, `coursera`, `udemy`…) when the URL shows it; `creator`, `duration` and `image` (a preview image URL from the page) when known. Body = what it teaches or shows and why it was saved (3–6 key points when the page was read). One resource per URL/book.
- Status: idea/note `active|archived`; resource `active` (saved for later) · `doing` (watching/reading/taking it) · `done` (finished: `completed: <today>`) · `archived`. «دارم می‌بینمش» / «تمومش کردم» about a saved link updates that resource's status. Archive instead of deleting.
